# Victor Laitila - Portfolio

Hi! I'm Victor, a software engineer based in Helsinki. This is the source of my personal portfolio,
where you can find my projects, skills and experience.

**🌐 [victorlaitila.github.io/portfolio](https://victorlaitila.github.io/portfolio/)**

## Built with

- React, TypeScript, Tailwind CSS and Vite, hosted on GitHub Pages
- A single YAML file of career data that drives both the site and my downloadable CV, which is
  generated as a PDF with Python
- Unit, CV and end-to-end tests (Vitest, pytest, Playwright) that run in GitHub Actions on every change

## Running it locally

```bash
npm install
npm run dev    # http://localhost:8080/portfolio/
npm run check  # all quality checks
```
